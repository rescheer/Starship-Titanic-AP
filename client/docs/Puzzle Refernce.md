# Puzzle Reference
These are not official names from the code, these are just names I came up with. You could get pretty granular with how you defined a single puzzle, but I tried to keep each one self-contained and thematically linked. 

## 3rd (SGT) Class Puzzles
### 2nd Class Upgrade
- *Prerequisites:*
  - *Items:* None
  - *Puzzles:* None
- *Items Used:*: None
- *Rewards/Grants:* Magazine, 2nd Class Upgrade
- *Prerequisite For Puzzles:* [TODO]
- *Summary:* Go to your assigned SGT Class Stateroom. Using the PET controls, extend and inflate the bed, then activate the TV. This allows you to get into bed and look at the TY. Switch it on, then change it to channel 3. After the ding sound, exit your room into the SGT Lobby and go to the Succ-U-Bus there. Click receive on the PET controls to get the Magazine. Give the Magazine to the Deskbot in the Embarkation Lobby.
- *Possible Completion Detection Methods:* Intercept the Class Upgrade function [DONE]

### Mother
- *Prerequisites:*
  - *Items:* None
  - *Puzzles:* None
- *Items Used:*: Feather
- *Rewards/Grants:* Blue fuse (FanBridge), OlfactoryCentre
- *Prerequisite For Puzzles:* Titanic Titillator, Titania Repair
- *Summary:* Pick up the parrot in the Parrot Lobby, then exit the room. The parrot will escape you inventory and leave behind a feather. Put the feather in the Mother Succ-U-Bus's tray in the Bilge Room and attempt to send it anywhere. Mother will cough up a body containing the Blue fuse (FanBridge) and the OlfactoryCentre.
- *Possible Completion Detection Methods:* The rnv changes to [47, 1, 2] when the body comes out
